# Secure Cloud Infrastructure Lab

A security-focused AWS infrastructure project built using Terraform
and Python.

## Project Goals

This project explores the design and implementation of secure cloud
infrastructure using Infrastructure as Code.

Planned areas of focus include:

- AWS network segmentation
- Infrastructure as Code with Terraform
- Identity and access management
- Least-privilege security controls
- Encryption and secrets management
- Security logging and monitoring
- Automated cloud security auditing with Python
